## 🏙️ O Projeto Ivaitá

**Ivaitá-SP** é um município fictício do interior de São Paulo desenvolvido como um projeto multidisciplinar de **worldbuilding, identidade visual, storytelling, comunicação, audiovisual, UX/UI e desenvolvimento de software**.

A proposta parte de uma pergunta:

> **Até onde é possível construir uma cidade que não existe e, ainda assim, fazê-la possuir a coerência histórica, visual, cultural, institucional e digital de um município real?**

Ivaitá não foi criada apenas como cenário para um site fictício.

A cidade possui território, história, população, bairros, distritos, patrimônio, símbolos, arquitetura, tradições, festas, serviços públicos, paisagens, comunicação institucional e produtos digitais próprios.

Cada uma dessas partes pertence ao mesmo universo e segue um **cânone compartilhado**, permitindo que uma decisão tomada na história ou na geografia da cidade também seja respeitada em fotografias, mapas, vídeos, campanhas, interfaces e serviços digitais.

## 🌎 Worldbuilding

Ivaitá é tratada como uma cidade que possui passado, presente e continuidade.

Seu universo inclui elementos como:

- formação histórica e territorial;
- Centro Histórico e expansão urbana;
- bairros, distritos e regiões rurais;
- Rio Paranapanema;
- Alto dos Vinhedos;
- patrimônio arquitetônico;
- memória ferroviária;
- agricultura e viticultura;
- famílias e personagens históricos;
- festas e tradições;
- equipamentos públicos;
- turismo e natureza;
- desenvolvimento urbano e econômico.

### Continuidade é uma regra do projeto

O universo não é reconstruído do zero a cada nova peça.

Quando um elemento é estabelecido, ele passa a orientar as próximas representações.

```text
MAPA
  ↓
define onde os elementos estão

FOTOGRAFIA / DIREÇÃO DE ARTE
  ↓
define como esses elementos parecem

STORYTELLING
  ↓
define sua história e significado

COMUNICAÇÃO
  ↓
transforma isso em conteúdo

PLATAFORMA DIGITAL
  ↓
conecta tudo em uma experiência navegável
```

Dessa maneira, um edifício, uma paisagem ou uma tradição pode aparecer em diferentes mídias sem perder sua identidade.

## 📷 Construção visual da cidade

Ivaitá também está sendo construída visualmente por meio de mapas, imagens, direção de arte e produção audiovisual.

Entre as regiões e locais desenvolvidos estão:

**Centro Histórico** · **Sede Nova** · **Nova Ivaitá** · **Alto dos Vinhedos** · **Centro Logístico Rio Itararé** · **Parque Vale Verde** · **Rio Paranapanema**

Além de equipamentos públicos, praças, patrimônio ferroviário, igrejas, propriedades rurais, áreas naturais e diferentes paisagens do município.

### Princípio visual

> **Mapa define onde. Fotografia define como.**

Quando uma representação visual é consolidada, ela passa a funcionar como referência daquele lugar ou objeto.

Novos ângulos procuram preservar arquitetura, geografia, vegetação, vias, ferrovia e posição relativa dos elementos, tratando a cidade como um ambiente contínuo em vez de uma coleção de imagens independentes.

# 🚀 Executando o projeto

## Requisitos

É necessário possuir **Node.js** e **npm** instalados.

Clone ou baixe o projeto e instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local da aplicação.

### Build de produção

```bash
npm run build
```

A compilação será criada em:

```text
dist/
```

## ☁️ Deploy

A versão demonstrativa é hospedada no **Cloudflare Pages**.

O fluxo utilizado atualmente é:

```text
Projeto
   │
   ▼
npm run build
   │
   ▼
dist/
   │
   ▼
ZIP
   │
   ▼
Cloudflare Pages
   │
   ▼
ivaita.pages.dev

Para publicar uma atualização:

1. realize as alterações desejadas;
2. execute `npm run build`;
3. compacte o conteúdo da pasta `dist`;
4. abra o projeto no Cloudflare Pages;
5. crie um novo deployment;
6. envie o ZIP.

**https://ivaita.pages.dev/**

# 🔄 Como o Admin atualiza o Portal

Os arquivos JSON funcionam como **estado inicial**.

Ao criar, editar, publicar, desativar ou excluir conteúdos pelo painel administrativo, a aplicação persiste as alterações no `localStorage`.

```text
JSON inicial
     │
     ▼
Painel Administrativo
     │
     ▼
localStorage
     │
     ▼
Portal Público
```

As chaves utilizam o padrão:

```text
ivaita-portal-*
```

Isso significa que as alterações:

- aparecem no portal no mesmo navegador;
- permanecem após atualizar a página;
- não modificam fisicamente os JSONs;
- não são compartilhadas automaticamente entre dispositivos;
- ainda não representam persistência em banco de dados.

### Restaurando a base inicial

Para voltar aos dados dos JSONs, remova do armazenamento local do navegador as chaves:

```text
ivaita-portal-*
```

Sem os dados persistidos, a aplicação volta a utilizar sua base inicial.

# ⚙️ Arquitetura atual

A versão atual funciona como um **protótipo frontend funcional**.

A persistência local permite demonstrar a integração entre administração e portal sem exigir backend.

### Atualmente

```text
Admin
  ↓
localStorage
  ↓
Portal
  ↓
Mesmo navegador
```

### Evolução futura

Uma arquitetura multiusuário poderá substituir essa camada por:

```text
Portal / Admin
      ↓
Autenticação
      ↓
API
      ↓
Banco de Dados
      ↓
Armazenamento
```

Isso permitirá persistência centralizada, múltiplos usuários e sincronização entre dispositivos.

## 🧰 Processo criativo e ferramentas

O universo de Ivaitá é desenvolvido por meio de um processo híbrido que combina **direção criativa, design tradicional, desenvolvimento de software e inteligência artificial generativa**.

A IA generativa é utilizada como uma das ferramentas do processo para explorar e produzir elementos como conceitos visuais, imagens, cenas, materiais audiovisuais, textos, storytelling, worldbuilding e apoio ao desenvolvimento.

Esses materiais passam por um processo de **direção, seleção, edição, composição e continuidade**, buscando preservar o cânone e a identidade estabelecida para o município.

Ferramentas tradicionais de design, edição e desenvolvimento também fazem parte do fluxo de produção.

### Ferramentas utilizadas

| Área | Ferramentas |
| --- | --- |
| 🎨 Design e identidade visual | Adobe Illustrator, Adobe Photoshop e Figma |
| 🎬 Edição e produção audiovisual | Movavi Video Editor |
| 💻 Desenvolvimento | Visual Studio Code |
| ✨ Criação generativa | Ferramentas de IA generativa para texto, imagem, vídeo, áudio e apoio ao desenvolvimento |
| 🌐 Publicação | GitHub e Cloudflare Pages |

O processo pode envolver diferentes etapas:

```text
Pesquisa e conceito
